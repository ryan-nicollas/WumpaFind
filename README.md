## ✨ Sobre o WumpaFind

O **WumpaFind** nasceu como um projeto de estudo e portfólio com o objetivo de praticar o desenvolvimento de uma aplicação web completa utilizando uma API externa.

A aplicação se comunica com a API do **TMDB (The Movie Database)** para buscar informações reais sobre filmes.

Além do frontend, o projeto possui um pequeno backend em **Node.js + Express**, responsável por realizar as requisições para o TMDB sem expor o token da API diretamente no navegador.

---

## 🎥 Funcionalidades

🔎 **Pesquisa de filmes**  
Pesquise filmes pelo nome utilizando dados do TMDB.

🔥 **Filmes populares**  
Ao abrir o WumpaFind, uma seleção de filmes populares é carregada automaticamente.

🎬 **Detalhes do filme**  
Clique em qualquer filme para abrir uma janela com informações adicionais.

⭐ **Avaliações**  
Veja a nota média de cada filme.

📅 **Ano de lançamento**  
Consulte rapidamente quando o filme foi lançado.

⏱️ **Duração**  
Veja a duração do filme em horas e minutos.

🎭 **Gêneros**  
Os gêneros são exibidos diretamente na página de detalhes.

📖 **Sinopse**  
Leia uma descrição do filme sem precisar sair da aplicação.

📱 **Design responsivo**  
Interface adaptada para computadores e dispositivos móveis.
